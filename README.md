## `> cat projects.md`

### Dune Dragon: AI Suite for Students

A **FastAPI + OpenAI** backend that turns raw student responses into real-time, personalized study recommendations. Structured prompt engineering handles the parsing, and **SQLAlchemy** models pipe student progress into an interactive educator dashboard that surfaces class-wide metrics teachers can actually act on.

### StartupScope AI: Intelligent Job Discovery Platform

An end-to-end pipeline that scrapes, cleans, and ingests **2,000+ job listings per week** into a **PostgreSQL** database hosted on **AWS RDS**. A **FastAPI** service deployed on **EC2** runs keyword-matching against user-inputted skills, so job hunting stops feeling like a lottery and starts feeling like a search.

A secure **Java REST API** for an educational forum, built on **MVC architecture** with token-based authentication and password hashing. Desktop client written in **JavaFX**, and a serious testing push with **JUnit** raised project code coverage from **60% to 95%**.
